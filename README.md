# Roast & Toast 🔥👼

A dual-mode phrase generator: brutal roasts or glowing toasts, one-tap copy and share. Vanilla HTML/CSS/JS PWA, no build step.

## Setup
1. Open `app.js` and set `TINYFN_API_KEY` in the `CONFIG` object to your TinyFN key (already filled in) (Toast mode needs it; Roast mode needs no key).
2. Push this folder to a GitHub repo and connect it to Cloudflare Pages (build command: none, output directory: `/`).
3. Replace `preview.png` with your own 1200×630 social image if you like.

## Files
- `index.html`, `styles.css`, `app.js`: the app
- `manifest.json`, `sw.js`, `icons/`: PWA install and offline shell
- `preview.png`: Open Graph / Twitter image

## APIs
- Roast: `https://evilinsult.com/generate_insult.php?lang=en&type=json`
- Toast: `https://api.tinyfn.io/v1/fun/compliment` with an `X-API-Key` header

## Security note
Anything in `app.js` is public once deployed, so your TinyFN key will be visible to visitors. Use a key with limited quota, or proxy the call through a Cloudflare Worker.

## Disclaimer
Insults are generated by third-party APIs for entertainment purposes only. Do not use this to legitimately bully or harass individuals.
